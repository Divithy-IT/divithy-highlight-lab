# Bezpieczeństwo

Nie dołączaj do publicznych zgłoszeń prywatnych nagrań, transkrypcji,
pełnych lokalnych ścieżek ani danych osób słyszalnych w materiale.

Podatności zgłaszaj prywatnie przez **Report a vulnerability** w zakładce
Security repozytorium. Do odtworzenia problemu użyj krótkiego sztucznego
materiału testowego.
